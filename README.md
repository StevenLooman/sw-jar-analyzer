# sw-jar-analyzer

Canonical Smallworld Magik JAR/bytecode reading and analysis library. Extracted from
`sw5-jacoco-reporter`'s `sw5lib`, plus a `class_info` metadata parser. Package
`nl.ramsolutions.sw.magik.jaranalyzer`. Consumed as a git submodule by `sw5-jacoco-reporter`
and other Smallworld Magik tooling.
